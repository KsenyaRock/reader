# Читалка

Власний плеєр аудіокниг: EPUB озвучується на ПК (Windows) і слухається на iPhone як веб-додаток (PWA) зі швидкістю 0.5–3× і керуванням із екрана блокування.

- `site/` — плеєр (чистий HTML + JS, без збірки). Сайт на Netlify публікує цю теку.
- `tool/` — програма озвучки для Windows (`audiobook_tool.py`), інструкція в `tool/ЧИТАЙ-МЕНЕ.txt`.
- `tests/` — автотести, запускаються GitHub Actions на кожен push.
- `sql/` — скрипти Supabase (з'являться на етапі підключення бази; таблиці лише з префіксом `reader_`).

## Гілки
Робота лише в `dev` (безкоштовне прев'ю на Netlify). У `main` зливається тільки опубліковане за словом власника.

## Безпека
У репозиторії немає й не повинно бути токенів, ключів і паролів.

## Тести
```
python3 -m unittest discover -s tests/tool -v     # програма озвучки (з заглушкою замість мережі)
python3 -m unittest discover -s tests/site -v     # сайт і пошук секретів
python3 tests/run_client.py                       # плеєр у Chromium (потрібен playwright)
```
Автотести запускає GitHub Actions на кожен push у `dev` і `main`. Книгу для клієнтського тесту створює справжня програма озвучки; замість сервісу Microsoft використовується заглушка `tests/tool/stub/edge_tts.py`, яка пише тихий MP3.

## Версії
Версія плеєра — `VERSION` у `site/index.html`; вона ж у назві кешу `site/sw.js` (тест слідкує, щоб збігалися).
